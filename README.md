# SULIVAN
Synergistic Understanding and Learning with Interactive robotics, computer Vision, Augmented reality, and Neural networks

## Environment
### Hardware
 * Beam Projector(FHD)
   * The projector needs to be configured as second display placed the left side of main display.
 * Camera(FHD required, Supports 4K)
 * A Windows PC with NVIDIA GPU

### Software
 * Python 3.12
   * Using anaconda or miniconda is recommended.
  ```bash
   conda create -n sulivan python=3.12
   ```
 * CUDA 13.1.1
   * https://developer.nvidia.com/cuda-toolkit
 * cuDNN 9.19.1
   * https://developer.nvidia.com/cudnn
 * ffmpeg (Install & Add to Environment Variables)
   * https://phoenixnap.com/kb/ffmpeg-windows
 * Visual Studio Build Tools "Desktop development with C++"
   * https://visualstudio.microsoft.com/ko/visual-cpp-build-tools/

 * Configure Python environment
   * Open Anaconda Prompt and change directory to SULIVAN project folder
  ```bash
  conda activate sulivan
  pip install torch==2.9.1 torchvision==0.24.1 torchaudio==2.9.1 --index-url https://download.pytorch.org/whl/cu130
  pip install ffmpegcv[cuda]==0.3.16
  pip install -r requirements.txt
  ```

## Configuration
 * Open a console in SULIVAN directory
 * Clone the scenario repository
 ```bash
 git clone {github link of your sulivan scenarios repo} scenarios
 ```
 * Copy **config_sample.py**, and rename to **config.py**
 * If you have Camera calibration files(Calibration matrix, Distortion coefficients) generated by OpenCV, You can load and apply it. (Read config)

## Launch
 * Just launch main.py
  ```bash
  conda activate sulivan
  python main.py
  ```

## Note
 * Please use Visual Studio Code for development.
 * If you use NVIDIA GPU older than RTX 2000 Series, Please use CUDA 12.6 and cuDNN 8.9.7. (CUDA 13 requires RTX 2000 family or newer)
